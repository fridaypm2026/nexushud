# NexusHUD - App Store Publishing Guide

Complete guide for publishing NexusHUD to Apple App Store and Google Play Store.

---

## 📋 Prerequisites

### Development Environment
- **Node.js** 18+ installed
- **Xcode** (for iOS) - macOS required
- **Android Studio** (for Android)
- **Capacitor CLI** installed globally: `npm install -g @capacitor/cli`

### Required Accounts
- **Apple Developer Account** - $99/year
- **Google Play Console Account** - $25 one-time fee

### Code Signing
- **iOS**: Apple Developer certificates and provisioning profiles
- **Android**: Keystore file for signing releases

## 🚀 Part 1: Build Native Apps with Capacitor

### Step 1: Install Capacitor Dependencies

```bash
cd /data/.openclaw/workspace/app

# Install Capacitor core packages
npm install @capacitor/core @capacitor/cli

# Install platform-specific packages
npm install @capacitor/ios @capacitor/android

# Install useful plugins
npm install @capacitor/splash-screen @capacitor/status-bar @capacitor/keyboard @capacitor/push-notifications
```

### Step 2: Initialize Capacitor (First Time Only)

```bash
# Initialize Capacitor with your app details
npm run cap:init
```

This will use the configuration from `capacitor.config.ts`.

### Step 3: Build Web App

```bash
# Build the React app for production
npm run build
```

This creates the `dist/` folder with optimized production files.

### Step 4: Add iOS Platform

```bash
# Add iOS platform
npm run cap:ios

# Open in Xcode
npx cap open ios
```

**Requirements:**
- macOS with Xcode installed
- Apple Developer account configured in Xcode

### Step 5: Add Android Platform

```bash
# Add Android platform
npm run cap:android

# Open in Android Studio
npx cap open android
```

**Requirements:**
- Android Studio installed
- Android SDK configured

### Step 6: Sync Changes

After any web app changes:

```bash
# Build web app
npm run build

# Sync changes to native projects
npm run cap:sync
```

## 🍎 Part 2: Apple App Store Submission

### Step 1: Configure iOS Project in Xcode

1. Open `ios/App/App.xcworkspace` in Xcode
2. Select the project root → **General** tab
3. Set **Bundle Identifier**: `com.nexushud.app`
4. Set **Version**: `1.0.0`
5. Set **Build**: `1`
6. Select **Team** (your Apple Developer account)

### Step 2: Configure App Icons & Splash Screen

**App Icon Requirements:**
- 1024×1024px PNG (App Store)
- Various sizes for different devices (generated by Xcode)

**Splash Screen:**
- Create `ios/App/App/Assets.xcassets/Splash.imageset/`
- Add dark theme splash screen images

**Tool Recommendations:**
- Use [App Icon Generator](https://www.appicon.co/) for all sizes
- Or use [Icon Kitchen](https://icon.kitchen/)

### Step 3: Configure Signing & Capabilities

1. In Xcode → **Signing & Capabilities**
2. Enable **Automatically manage signing**
3. Select your **Team**
4. Add capabilities if needed (Push Notifications, etc.)

### Step 4: Build & Archive

1. In Xcode, select **Any iOS Device** as build target
2. **Product** → **Archive**
3. Wait for archive to complete
4. **Distribute App** → **App Store Connect**
5. Follow prompts to upload

### Step 5: App Store Connect Setup

1. Go to [App Store Connect](https://appstoreconnect.apple.com/)
2. Click **My Apps** → **+** → **New App**
3. Fill in app information:
   - **Platform**: iOS
   - **Name**: NexusHUD
   - **Primary Language**: English (US)
   - **Bundle ID**: com.nexushud.app
   - **SKU**: nexushud-ios-2025
   - **User Access**: Full Access

### Step 6: App Information

**App Description** (see ASO section below)

**Keywords** (100 char max):
```
ai assistant,jarvis,command center,voice control,automation,smart assistant,personal ai
```

**Support URL**: Your website or GitHub page
**Marketing URL**: Your landing page

### Step 7: Pricing & Availability

- **Price**: Free (or set your price)
- **Availability**: All countries (or select specific ones)

### Step 8: App Privacy

Prepare privacy policy and answer App Store privacy questionnaire:
- Does your app collect data?
- What types of data?
- How is data used?
- Is data shared with third parties?

### Step 9: Screenshots & Preview

**Required Screenshots:**
- 6.7" iPhone (1290 × 2796px) - iPhone 15 Pro Max
- 6.5" iPhone (1284 × 2778px)
- 5.5" iPhone (1242 × 2208px)
- 12.9" iPad Pro (2048 × 2732px)

**Recommended Tool:**
- [Previewed](https://previewed.app/) for mockups
- [App Launchpad](https://theapplaunchpad.com/) for screenshots

### Step 10: Submit for Review

1. Upload build from Xcode
2. Select build in App Store Connect
3. Fill in **What's New** (version notes)
4. Fill in **App Review Information**:
   - Contact info
   - Demo account (if login required)
   - Notes for reviewer
5. Click **Submit for Review**

**Review Time**: Typically 24-48 hours

## 🤖 Part 3: Google Play Store Submission

### Step 1: Configure Android Project

1. Open `android/` in Android Studio
2. Edit `android/app/build.gradle`:
   - `applicationId "com.nexushud.app"`
   - `versionCode 1`
   - `versionName "1.0.0"`

### Step 2: Generate App Icons

Place icons in `android/app/src/main/res/`:
- `mipmap-mdpi/` - 48×48px
- `mipmap-hdpi/` - 72×72px
- `mipmap-xhdpi/` - 96×96px
- `mipmap-xxhdpi/` - 144×144px
- `mipmap-xxxhdpi/` - 192×192px

**Adaptive Icon:**
- `mipmap-anydpi-v26/ic_launcher.xml`
- Foreground + background layers (108×108dp each)

### Step 3: Create Keystore for Signing

```bash
# Generate keystore (do this ONCE and keep it safe!)
keytool -genkey -v -keystore nexushud-release-key.keystore \
  -alias nexushud -keyalg RSA -keysize 2048 -validity 10000

# You'll be prompted for:
# - Keystore password (SAVE THIS!)
# - Key password (SAVE THIS!)
# - Name, organization, etc.
```

**⚠️ CRITICAL:** Back up this keystore! If lost, you can't update your app.

### Step 4: Configure Signing in Android Studio

1. File → **Project Structure** → **Modules** → **app**
2. **Signing Configs** → **+** → Add release config:
   - **Store File**: Path to `.keystore`
   - **Store Password**: Your keystore password
   - **Key Alias**: nexushud
   - **Key Password**: Your key password

### Step 5: Build Release APK/AAB

```bash
# Build App Bundle (AAB) - recommended for Play Store
cd android
./gradlew bundleRelease

# Output: android/app/build/outputs/bundle/release/app-release.aab

# Or build APK
./gradlew assembleRelease
# Output: android/app/build/outputs/apk/release/app-release.apk
```

### Step 6: Google Play Console Setup

1. Go to [Google Play Console](https://play.google.com/console/)
2. **Create app**
3. Fill in details:
   - **App name**: NexusHUD
   - **Default language**: English (United States)
   - **App or game**: App
   - **Free or paid**: Free

### Step 7: Store Listing

**App Details:**
- **App name**: NexusHUD
- **Short description** (80 chars):
  ```
  Your personal AI command center — like having Jarvis in your pocket
  ```

- **Full description** (4000 chars max) - see ASO section

**App Category:**
- **Category**: Productivity
- **Tags**: AI, Assistant, Automation, Voice Control

### Step 8: Graphics Assets

**Required:**
- **App icon**: 512×512px PNG (32-bit, no transparency)
- **Feature graphic**: 1024×500px JPG/PNG
- **Phone screenshots**: Min 2, max 8 (320-3840px)
- **7-inch tablet screenshots**: Min 2 (optional)
- **10-inch tablet screenshots**: Min 2 (optional)

**Optional:**
- **Promo video**: YouTube URL
- **TV banner**: 1280×720px

### Step 9: Content Rating

1. Complete questionnaire about app content
2. Get rating (e.g., "Everyone", "Teen", etc.)
3. This is required for all regions

### Step 10: Release Setup

1. **Countries/regions**: Select where to publish
2. **Pricing**: Free or set price per country
3. **Upload AAB**: Upload your `app-release.aab`
4. **Release name**: v1.0.0
5. **Release notes**: What's new in this version

### Step 11: Submit for Review

1. Complete all sections (content rating, target audience, etc.)
2. Click **Review release**
3. Fix any warnings/errors
4. Click **Start rollout to Production**

**Review Time**: Typically a few hours to a few days

## 🐛 Common Issues & Solutions

### iOS Build Errors

**Problem:** "No matching provisioning profile"
**Solution:** 
1. Xcode → Preferences → Accounts
2. Download Manual Profiles
3. Enable "Automatically manage signing"

**Problem:** "Code signing error"
**Solution:** Clean build folder (Cmd+Shift+K) and rebuild

### Android Build Errors

**Problem:** "SDK not found"
**Solution:** 
1. Android Studio → Preferences → Android SDK
2. Install latest SDK and build tools

**Problem:** "Gradle sync failed"
**Solution:** File → Invalidate Caches / Restart

### Capacitor Issues

**Problem:** Changes not reflected in app
**Solution:** 
```bash
npm run build
npm run cap:sync
```

**Problem:** "Web assets missing"
**Solution:** Ensure `dist/` folder exists and contains built files
